# cloudii・technologies 企業サイト

架空のソフトウェア開発会社「cloudii・technologies」のコーポレートサイト（1ページ構成）です。
HTML・CSS・JavaScript をすべて `index.html` 1ファイルにまとめており、ビルドやサーバーは不要です。

> 掲載している会社情報・導入事例・数値などはすべて架空のサンプルです。

## サイトの概要

| セクション | 内容 |
| --- | --- |
| ヘッダー / お知らせバー | ナビゲーション、最新のお知らせを自動で切り替えて表示 |
| ヒーロー | キャッチコピーと問い合わせへの導線 |
| About | ミッションと3つのバリュー |
| Services | Web・モバイル開発、クラウドインフラ、AI・データ活用、DXコンサルティング、運用保守 |
| 実績数値 | 支援企業数などをカウントアップ表示 |
| Works | 導入事例（3件） |
| Flow | ヒアリングからリリース・運用までの5ステップ |
| News | お知らせ一覧 |
| Contact | 会社情報とお問い合わせフォーム（デモのため送信はされません） |

### 主な特徴

- レスポンシブ対応（スマートフォンではハンバーガーメニューに切り替え）
- OS の設定に合わせたダークモード対応
- スクロールに合わせたフェードイン表示（「視差効果を減らす」設定時は無効）
- フォントは Google Fonts（Noto Sans JP / Inter）から読み込み

## ブラウザで表示する手順

1. このリポジトリをクローン、またはダウンロードします。

   ```sh
   git clone <リポジトリのURL>
   cd company-site
   ```

2. `index.html` をブラウザで開きます。方法は次のいずれかです。
   - エクスプローラー（macOS では Finder）で `index.html` をダブルクリックする
   - `index.html` をブラウザのウィンドウにドラッグ＆ドロップする
   - コマンドで開く
     - Windows: `start index.html`
     - macOS: `open index.html`
     - Linux: `xdg-open index.html`

3. ページが表示されたら完了です。`index.html` を編集した場合は、ブラウザを再読み込み（F5 / Cmd+R）すると反映されます。

> フォントの読み込みにインターネット接続を使います。オフラインでも表示はできますが、フォントは端末の標準フォントになります。
